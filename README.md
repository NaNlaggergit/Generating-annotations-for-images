# Generating-annotations-for-images
Курсовой проект по дисциплине **«Машинное обучение»**.  
Тема: *Построение модели генерации описания изображения с использованием архитектуры CNN-RNN.*

---

## 📌 Описание проекта

Проект реализует систему автоматической генерации подписей к изображениям.  
В качестве датасета используется **Microsoft COCO** ([ссылка](https://cocodataset.org/#download)).

- **Encoder (CNN):** предобученная модель ResNet-152 без последнего слоя.
- **Decoder (RNN):** LSTM-модель, обучаемая для генерации текста по признакам изображения.
- **Фреймворк:** PyTorch.

---

## 🚀 Возможности

- Загрузка и подготовка датасета MS COCO.
- Обучение модели CNN-RNN для генерации описаний.
- Визуализация примеров изображений и соответствующих подписей.
- Сохранение и загрузка весов модели.
- Генерация аннотации к новым изображениям.
